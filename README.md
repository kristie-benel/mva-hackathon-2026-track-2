**Date:** October 24, 2026
**Pitch video:** [https://youtu.be/8876mq4rDfk](https://youtu.be/8876mq4rDfk)

## Summary

Mosaic variegated aneuploidy (MVA) is a *BUB1B* genetic disorder in which the BUBR1 protein degrades too quickly, causing mistakes in the cell's spindle checkpoint. We propose two small-molecule drugs to stabilize BUBR1: **nicotinamide riboside**, which boosts NAD+, and a **CBP/p300 inhibitor (inobrodib)**, which reduces protein acetylation. The two could eventually be combined. We recommend testing the proposal in mouse and *C. elegans* worm models.

These are hypotheses for follow-up, not evidence that any medicine works.

## Approach

This submission is a literature-based treatment proposal. It does not include analysis code. The report explains the variant mechanism, the chosen drugs, and how they relate to the mechanism.
